**Italian Sub-Municipal Resilience Map**

Interactive web map visualizing the final course project for Applied Statistics at Politecnico di Milano.
This was displayed in the final poster presentation of course projects.



**About the Project**

This project calculates a resilience index for Italian sub-municipalities. To overcome the lack of existing data at this granular level, we developed a downscaling methodology inspired by thermodynamics, mapping physical concepts to territorial resilience metrics.
